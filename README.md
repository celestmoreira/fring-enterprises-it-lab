# Fring Enterprises: Enterprise IT Administration Lab

A hands-on enterprise IT home lab inspired by *Breaking Bad* and *Better Call Saul*.

## Project Overview

Fring Enterprises is a fictional organization with a centralized IT department supporting three business units:

- Los Pollos Hermanos —> Restaurant Operations
- Madrigal Logistics —> Distribution and Logistics
- Saul Goodman & Associates —> Legal Services

The goal of this project is to build practical IT support and systems administration skills through realistic employee onboarding, account management, endpoint administration, network troubleshooting, and access control scenarios.

## Technologies

**Planned:**
- Windows Server 2025
- Active Directory Domain Services
- DNS and Group Policy
- Windows 11
- Google Workspace Business
- VirtualBox
- Cisco Packet Tracer

## Learning Objectives

1. Understand how enterprise identity and access management works.
2. Create and manage Windows domain accounts.
3. Troubleshoot authentication and permission issues.
4. Administer Google Workspace users, groups, and shared drives.
5. Configure and troubleshoot simulated enterprise networks.
6. Document technical procedures and troubleshooting outcomes.
